# Агент для создания детской энциклопедии

AI-агент для генерации детской энциклопедии на базе Yandex AI Studio. Проект создаёт структуру тем, пишет markdown-статьи и сохраняет их в виде готовой папки энциклопедии.

## Что умеет

- генерировать несколько тематических разделов;
- создавать по несколько статей в каждой теме;
- хранить историю действий и уже созданные статьи в памяти агента;
- проверять итоговую структуру после генерации;
- использовать резервный сценарий, если модель вернула некорректный план.

## Требования

- Python 3.11+
- `api_key` для Yandex AI Studio
- `folder_id` из Yandex Cloud

## Быстрый старт

1. Установите зависимости:

```bash
pip install -r requirements.txt
```

2. Создайте `.env`:

```env
api_key=YOUR_API_KEY
folder_id=YOUR_FOLDER_ID
```

3. Запустите генерацию:

```bash
python encyclopedia_agent.py --path ./example --n 3 --m 3
```

Альтернативный запуск через пакет:

```bash
python -m encyclopedia --path ./example --n 3 --m 3
```

Параметры CLI:

- `--path` — директория для сохранения энциклопедии
- `--n` — число статей в каждой теме
- `--m` — число тем
- `--quiet` — отключает подробный вывод

## Текущая структура проекта

```text
.
├── encyclopedia/
│   ├── agent.py        # основная orchestration-логика
│   ├── cli.py          # разбор аргументов и запуск
│   ├── client.py       # создание клиента Yandex/OpenAI SDK
│   ├── constants.py    # доступные темы и константы
│   ├── models.py       # dataclass и pydantic-модели
│   ├── tools.py        # файловые инструменты агента
│   ├── utils.py        # общие утилиты
│   └── __main__.py     # запуск через python -m encyclopedia
├── tests/
│   └── test_project_structure.py
├── encyclopedia_agent.py
└── README.md
```

`encyclopedia_agent.py` сохранён как совместимый entrypoint и просто вызывает новый CLI.

## Архитектура

- `EncyclopediaAgent` отвечает за планирование, генерацию статей и финальную валидацию.
- `tools.py` инкапсулирует работу с файловой системой.
- `models.py` отделяет состояние выполнения от бизнес-логики.
- `client.py` изолирует конфигурацию API.
- `utils.py` содержит чистые функции, которые проще тестировать отдельно.

## Docker

Запуск через Docker:

```bash
docker-compose up --build
```

Результат будет сохранён в `./output/encyclopedia`.

## Проверка

Базовые тесты:

```bash
python -m unittest discover -s tests
```
