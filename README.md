# Агент для создания детской энциклопедии

AI-агент, построенный на фреймворке Yandex AI Studio, который автоматически генерирует детскую энциклопедию с использованием LLM и инструментов Function Calling.

## Возможности

- Создание структурированной детской энциклопедии с несколькими темами
- Генерация статей в формате Markdown
- Агентский паттерн с инструментами:
  - `mkdir` — создание директорий
  - `grep` — поиск текста в файлах
  - `WriteArticle` — создание и сохранение статей
- Система памяти для отслеживания созданного контента и цитирования

## Требования

- Python 3.11+
- API ключ Yandex Cloud (AI Studio)
- Yandex Cloud folder_id

## Установка

### Локальный запуск

1. Клонируйте репозиторий:
```bash
cd MAI_DL_LAB1
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` с вашими credentials:
```env
api_key=YOUR_API_KEY
folder_id=YOUR_FOLDER_ID
```

4. Запустите агента:
```bash
python encyclopedia_agent.py --path ./example --n 3 --m 3
```

Параметры:
- `--path` — путь для сохранения энциклопедии (по умолчанию: `./encyclopedia`)
- `--n` — количество файлов в каждой теме (по умолчанию: 3)
- `--m` — количество тем (по умолчанию: 3)

### Запуск через Docker

1. Убедитесь, что у вас установлен Docker и Docker Compose

2. Создайте файл `.env` с вашими credentials:
```env
api_key=YOUR_API_KEY
folder_id=YOUR_FOLDER_ID
```

3. Соберите и запустите контейнер:
```bash
docker-compose up --build
```

Это создаст энциклопедию в папке `./output/encyclopedia`.

## Архитектура

```
encyclopedia_agent.py
├── Memory          # Класс для хранения истории работы
├── Mkdir           # Инструмент: создание директорий
├── Grep            # Инструмент: поиск в файлах  
├── WriteArticle    # Инструмент: создание статей
└── Agent           # Главный класс агента с циклом обработки
```

## Пример работы

Агент получает задачу создать энциклопедию и:
1. Создает M директорий с названиями тем
2. В каждой директории создает N файлов со статьями
3. Каждая статья написана в стиле детской энциклопедии
4. Агент помнит что создал и может ссылаться на предыдущие статьи

## Структура вывода

```
encyclopedia/
├── Космос/
│   ├── planets.md
│   ├── stars.md
│   └── astronauts.md
├── Животные/
│   ├── mammals.md
│   ├── birds.md
│   └── insects.md
└── Наука/
    ├── physics.md
    ├── chemistry.md
    └── biology.md
```

Каждая статья содержит:
- Заголовок
- Название раздела
- Основной контент
- Дату создания
